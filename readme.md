# JavaScript Drum Kit

An interactive drum kit that can be played using keyboard keys or mouse clicks. Each key triggers a unique drum sound with a visual animation effect.

## Features

- 9 different drum sounds
- Keyboard controls (A-L keys)
- Click/tap support for mobile devices
- Visual feedback with animations
- Responsive design for all screen sizes

## How to Play

1. Use the following keyboard keys:

   - `A` - Clap
   - `S` - Hi-hat
   - `D` - Kick
   - `F` - Open Hat
   - `G` - Boom
   - `H` - Ride
   - `J` - Snare
   - `K` - Tom
   - `L` - Tink

2. Alternatively, click/tap the circular buttons on screen

## Technical Details

The project uses:

- HTML5 Audio API for sound playback
- CSS Grid for layout
- CSS Transforms for animations
- Vanilla JavaScript for event handling

## Browser Support

Works on all modern browsers that support HTML5 Audio and CSS Grid.

## Installation

1. Clone this repository
2. Open `index.html` in your browser
3. Start playing!
